# 🗳️ Blockchain Voting System  

A decentralized **Blockchain-based Voting Application** built using **Solidity, Ganache, Truffle, and MetaMask**.  
This project demonstrates how blockchain can be used to build a secure, transparent, and tamper-proof voting system.  

---

## 🚀 Highlights  
- 🔒 Secure and transparent voting process  
- 🆔 Each voter can vote only once (preventing duplication)  
- 🌐 Smart contract deployed on Ethereum test network  
- 🦊 MetaMask integration for authentication and transactions  
- 📊 Real-time vote counting stored on the blockchain  

---

## 🛠 Tech Stack  
- **Smart Contracts:** Solidity  
- **Blockchain:** Ethereum (Ganache local blockchain for testing)  
- **Frameworks & Tools:** Truffle, Ganache, MetaMask  
- **Frontend:** HTML, CSS, JavaScript (Web3.js for blockchain interaction)
